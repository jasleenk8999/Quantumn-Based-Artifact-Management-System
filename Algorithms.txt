#Aircraft Engine Health Prediction Algorithm

1. Start
2. Input
    Read engine ID, location, sensor values
3. Store Data
    Save sensors in history
4. Preprocess
    Normalize using scaler
5. Current Prediction
	Quantum model → score → apply smoothing
6. Current Status
	Classify: High / Moderate / Healthy
7. Future Prediction
	Last 3 values → LSTM → smoothing → apply rules
8. Trend
	Check last 3 scores → Increasing / Decreasing / Stable
9. Ranking
	Store score → compute rank
10. Nearest Airport
	Find using R-tree
11. Decision
	Generate using AI
12. Output
	Return all results
13. End

Overall Time Complexity: O(N)
Overall Space Complexity: O(N)

#R-Tree Algorithm

1. Start
2. Input
    Set of spatial objects (latitude, longitude)
3. Initialize
    Create empty R-tree index
4. Insert Data
    Insert (lat, lon) as rectangle into R-tree
5. Query (Nearest Search)
    Input query point (lat, lon)
    Traverse tree to find nearest object
6. Selection
    Compare distances
    Choose minimum distance object
7. Output
    Return nearest location (airport/hangar)
8. End

Overall Time Complexity: 1.Insertion: O(log N)
                         2.Search: O(log N)
Overall Space Complexity: O(N)

R-Tree is used to efficiently find the nearest airport (hangar) based on engine location.

#Double-Ended Priority Queue (DEPQ) Algorithm

1. Start
2. Input
    Set of items with scores
3. Initialize
    Create two heaps:
    Min-heap (stores smallest scores)
    Max-heap (stores largest scores)
    Shared active flags for lazy deletion
4. Insertion
    Add item to both heaps
    Mark as active
5. Get Maximum (Highest Risk)
    Clean max-heap (remove inactive items)
    Return maximum score item
6. Get Minimum (Healthiest)
    Clean min-heap (remove inactive items)
    Return minimum score item
7. Update Score
    Mark old entry as inactive
    Insert new score
8. Output
    Return required result
9. End

Overall Time Complexity: 1.Insertion: O(log N)
                         2.Get Max: O(log N)
                         3.Get Min: O(log N)
                         4.Update: O(log N)
Overall Space Complexity: O(N)
